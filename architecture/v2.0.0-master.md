## Key Rules & Directives

### 1. Model Quota Hierarchy
1. **Jules Cloud Sessions (100 sessions / 24h window):** Primary heavy code generator.
2. **Gemini Flash (Medium/Low):** Dedicated asynchronous Session Managers & PR monitors.
3. **Primary Orchestrator (Pro / Opus):** High-level task planning and PR gate review.

### 2. Subagent Polling Latency Rule (5-Minute Wait Timers)
- Flash Session Managers MUST use **300-second (5-minute) background schedule timers** between polls.
- This prevents token burn on `busy` session states and conserves >80% of context tokens.

### 3. Antigravity Gate Review
- Before merging any PR from Jules, the Orchestrator MUST inspect the diff for template overwrites or missing files.
- Run local verification (`npm run build`, unit tests) before executing `merge_pull_request`.
